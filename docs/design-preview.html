Mnemo — design preview

A visual read of DESIGN.md. Everything on this page is drawn from the real source: the palette and glyphs from tui-go/internal/theme/theme.go, the wordmark and mascot art from tui-go/internal/brand/brand.go. Nothing here is a mockup of a mockup — if a value changes in Go, change it here too, or better: treat this page as the place to decide, and then change Go.

Presets re-skin the palette and the mock transcript below. Any swatch can be dragged/tweaked by its colour box — the hex label and every preview update live.

1 · The palette

Fourteen values, each a role. The whole interface is allowed to use nothing else. The rule the current palette is built on: accent is pink because yellow is the terminal's own chrome colour, and an accent that appears everywhere is not an accent.

2 · The surface — one screen, not six panes

The transcript is the application. Everything else floats over it and is dismissed with esc. Below: the header band, the labelled rule, the transcript with its two-cell speaker gutter, a folded block, a live tool, a search hit, and the status line. Re-skin it with the presets above.

3 · The wordmark

Five letters, strokes three cells thick, a half-cell lip down and to the right in rosette brown — the same ink as the mascot's markings, which is what makes the logo and the mascot look related rather than merely adjacent. 83 cells wide; below 87 columns a 57-cell cut takes over; below that the wordmark is dropped and the tagline stands alone. A wordmark that wraps is not a wordmark.

4 · Glyphs

Every non-alphabetic character the interface may draw, from theme.Heavy. All of them live in the standard block and box-drawing ranges, so the whole thing renders on a plain monospace font. A glyph that needs Nerd Fonts is a glyph that is blank for somebody.

5 · Motion

Nothing blinks. The thinking animation is a dither band whose density travels — the eye reads direction, not a twitching character, and it is a pure function, so it is a unit test rather than something you have to sit and watch. One vocabulary, used twice: the same ramp draws the mascot's rosettes.

6 · Mascots

  
All drawn at 2 cells per marker, 40 cells wide. █ coat ·

Why the cat is hard to play with

    
Nyx is 20 rows × 28 markers (56 cells) with four shades, a ringed tail, mascara lines, a
    spotted belly and a walk cycle in four frames — three of which differ only in the legs. Every
    change means redrawing four frames and re-pinning the installer's copy. That is a lot of art for
    a mascot whose whole job is to say "hello, I am not a hang" on an empty screen.

    
The rules the next mascot must keep

    

      
rulewhy

      
Eyes are negative spacedrawn eyes plus a mouth read as a glare with teeth at this scale — shipped once, rejected

      
Exactly one accent-coloured runmore than one and the brand colour stops being a detail and becomes decoration; a test enforces it

      
Markers, never coloursshape and palette stay one thing each: one function turns a marker into a glyph plus a colour

      
Plain monospace onlyno Nerd Font requirement — the interface must render identically on a stock terminal

      
Tone from the 14-value palettea mascot with its own colours cannot be re-themed with the rest of the UI

      
≤ 12 rows, symmetricit must be redrawable by hand in a minute, and poseable without a walk cycle

    

  


  
  
7 · Direction — the Greek/Roman layer

  
The name already points here: Mnemo from Mnemosyne, memory personified and mother
  of the Muses. The interface currently speaks PICO-8 — a game console — which is where the pixel
  grammar and the palette came from. Nothing below has to be adopted wholesale; each row is
  independent.

  

    

      
layernowproposalcost

      
palettePICO-8: black ground, pink accent, orange coat
          pottery: black gloss ground, terracotta slip ink, ochre accent, oxblood for failure; the "Greek pottery" preset above
          one struct in theme.go; every pane follows

      
chromeheavy box-drawing rules
          a meander (Greek key) rule: ╪╪╪╪ / ▚▚▚▚ alternation, and a laurel divider for section heads
          one glyph string per role — the rule is already a single function

      
structure wordsblocks, gutter, band, overlay
          keep the code names, use the Greek layer in user-visible labels: agora for the palette, scroll for the transcript, amphora/vessel for memory, oracle for the model
          labels only; no refactor

      
memory areasEpisodic, Semantic, Procedural, Spatial, Salience, Executive
          keep the code names, name them after the Muses in the Memory overlay: Calliope (episodes), Clio (history/facts), Polyhymnia (procedure), Urania (spaces), Melpomene (pain markers), Thalia (executive)
          display strings in one overlay

      
mascotNyx, a Bengal cat (56 cells, 4 shades, walk cycle)
          one of the six above — owl, tortoise, serpent, bee, amphora; the cat can stay as a rare, larger cameo
          art in brand.go + the installer's copy + its diff test

      
voicelowercase, no exclamation marks, states facts
          unchanged. The restraint is the classical register — a temple does not shout
          zero

    

    
What must not change, whatever the theme

    
Fourteen colours and no more · eyes as negative space · one accent run per mascot · no Nerd
    Fonts · the accent never takes a colour the terminal already uses for chrome (yellow is
    warning) · every colour is a role, never a hue, so a second palette stays a value and
    not a rewrite.
