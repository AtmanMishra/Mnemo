## What's new

### A settings menu
- **`/settings`** opens a menu of everything you can tune; type to filter, `enter` to change,
  `esc` to leave. `/settings hops 20` changes one setting in a sentence, `/settings reset`
  puts one (or all) back, and `mnemo settings` does the same from a shell. Every setting
  has a default that is what Mnemo did before, so nothing changes until you change it.
  Choices are kept in `~/.mnemo/config.json` (only the ones that differ), and a value that
  does not fit is refused with the reason. The whole list: `docs/SETTINGS.md`.
- **Agents.** The message chain (12), the woken-turn budget ($0.50), sub-agent depth,
  sub-agents per agent and per conversation, message length and rate, the number of held
  messages, and how long `message_agent` waits for a reply.
- **Look.** Theme (it is remembered, as before), animation, the launch sequence, whether
  the sidebar starts open and how wide it is, the split layout, how fast the wheel scrolls,
  whether tool output starts expanded, how long toasts stay and how many show.
- **Behaviour.** Learning after runs, the check after changed code, the escalation model and how
  many failed checks it takes, how long a Python cell may run, and a default mode of `default` or `plan`.
- **Notifications.** The desktop notice, how long a turn must run to send one, and the daily update check.
- **Keys.** Fourteen chords can be rebound: palette, sidebar, find, expand, clear, thinking level,
  hub, playground, project switch, new agent, split, next layout, previous and next agent. The footer,
  the `?` panel, `/help` and the tool-output hints show the chords you set. A chord that the prompt
  needs for editing, or that another action holds, is refused.

### Safe by construction
- No setting loosens the permission gate: the default mode is `default` or `plan`, never `yolo`
  or `accept-edits`, and flags and environment variables still win for a run (`--no-reflect`,
  `MNEMO_NOTIFY=0`, …). The limits have fixed ceilings. The model has no tool that changes a
  setting, and an edit to `config.json` from the agent asks like any file outside the project. See
  `SECURITY.md`.

### Changed
- `/theme` and `mnemo update --auto` now go through the same store as the menu, in the same `state.json` as before.
- The sub-agent tool is offered according to the depth limit at the time a conversation starts; the
  roster enforces the limit on every spawn.

### Known
- Animation, the launch sequence, the sidebar's starting state, the default mode, the desktop notice
  and the update check are read at launch; the menu says so when you change one.
- Keys that belong to a particular screen (the hub's `l`/`u`, the sidebar's panes) are not rebindable.
