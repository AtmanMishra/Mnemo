## What's new

### Fixes you would have hit
- **Subscription `/login` works in the downloaded binary.** On v0.1.0 to v0.1.2 it
  failed with `Cannot find module './anthropic.js'`, and Bedrock models and image
  reads failed the same way. Every flow now loads from the binary, and the release
  builds fail if one would not.
- **Memory no longer reads "off" after a while.** `◈ off` now means the memory
  sidecar is not installed. If it is installed but slow to answer, the footer says
  `◈ busy` and keeps the last count.
- **Memory stays on your machine.** Remote embeddings are opt-in: set
  `MNEMO_EMBED_URL` and `MNEMO_EMBED_MODEL`. An `OPENROUTER_API_KEY` alone no longer
  sends anything anywhere, and the sidecar starts without your provider keys.
- **Esc with a message queued** no longer crashes the screen; the message goes back
  to the prompt. A login waiting on the browser can be cancelled with esc.
- **`mnemo -p` exits 1** with the reason when the model call fails (it used to exit 0).

### Windows install
- **A downloaded `mnemo.exe` installs itself.** It asks once, copies itself and the
  memory sidecar to `%USERPROFILE%\.mnemo\bin` and adds that folder to your user
  PATH. `mnemo install [--yes]` does the same without a question.
- **`mnemo doctor`** starts the memory sidecar, times its answer, and names the
  embedder and the log file. It warns when the `mnemo` on your PATH is a different
  file from the one running.
- **`mnemo uninstall`** moves a running `mnemo.exe` out of the way so the install
  folder (and, with `--deep`, the data folder) goes at once. Anything it cannot
  remove is named, and the exit code is 1.
- The site's Windows instructions lead with `irm https://mnemo.atmanmishra.dev/install.ps1 | iex`.

### Safety
A review of the permission gate, the memory layer, the interface and the install
path fixed about sixty problems, each with a test. The ones that matter most:
- A malformed `grants.json` no longer switches the gate off; it fails closed.
- Plan mode is no longer beaten by an allow rule.
- Deny rules can no longer be bypassed with quotes, `sudo -u`, `env -u`, `eval`,
  `timeout`, `xargs` or `find -exec`.
- The process environment, `.env`, `models.json` and `grants.json` are not readable
  by the agent's tools.
- Memory redaction catches more credential shapes (`hf_`, `ya29.`, Basic and Digest
  auth, webhook URLs, `*_PASS=`).

The full list is in `docs/REVIEW-2026-10.md`. The gate filters; it is not a sandbox.

## Known issues

- The Windows binary is not code-signed, so SmartScreen may warn on a browser
  download. The `irm | iex` and Scoop paths avoid it.
- Keys typed in the first second after the prompt appears can occasionally be dropped.
- The binary reports its version to MCP servers as 0.0.0.
- `git bisect run`, `git submodule foreach` and `npm install*` grants are not yet
  covered by the gate's option checks (see `SECURITY.md`).

Install or upgrade: `curl -fsSL https://mnemo.atmanmishra.dev/install.sh | sh`
(Windows: `irm https://mnemo.atmanmishra.dev/install.ps1 | iex`), or `mnemo update`.
