## What's new

### Safety
- **A grant no longer covers the form of a command that runs something else.** An
  approval for `git bisect`, `git submodule`, `git filter-branch`, `npm install`,
  `bun add`, `cargo install` or `go get` is for the plain subcommand. `git bisect run
  <cmd>`, `git submodule foreach <cmd>`, `git filter-branch`, and installing a named
  package (whose scripts run) are asked about each time, and "always" is not offered
  for them. Plain `npm install`, `git bisect start` and `git submodule status` keep
  their grants.
- **Plan mode no longer writes to memory.** `memory_remember` and `memory_steer` are
  refused in plan mode, like every other change. Reading memory still works.

### Interface
- **Agents page shortcuts.** `n` then Enter starts a new agent (it used to jump to the
  first one), `s` toggles a card in the split and `ctrl+s` opens exactly the chosen
  agents, and ctrl-modified keys no longer also fire the page's single-letter keys.
- **esc during a running tool** says "Interrupted", as it already did while the model
  was streaming, instead of "The operation was aborted."

### Project
- The CI runs the website's build and checks on every pull request. It used to run
  only on Vercel, after the merge.

## Known issues

- The Windows binary is not code-signed, so SmartScreen may warn on a browser
  download. The `irm | iex` and Scoop paths avoid it.
- Keys typed in the first second after the prompt appears can occasionally be dropped.
- The binary reports its version to MCP servers as 0.0.0.
- yolo and `-p` can still read `/proc/$PPID/environ` through bash (`SECURITY.md`).
- Memory: `distrusted` is a difference, not a ratio; skill nodes are global by label;
  a write that times out on the client can still be applied later. All three change
  recall or the sidecar protocol and are planned for 0.1.5 with the evals.

Install or upgrade: `curl -fsSL https://mnemo.atmanmishra.dev/install.sh | sh`
(Windows: `irm https://mnemo.atmanmishra.dev/install.ps1 | iex`), or `mnemo update`.
