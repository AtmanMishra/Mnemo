## What's new

### Hooks, schedules and language servers
- **Hooks** run your own commands before and after tool calls, prompts and sessions. A hook can stop
  a tool call; it cannot approve one the gate would refuse.
- **`mnemo schedule`** runs a prompt on a timer. A scheduled run is read-only (plan mode) unless the job
  says it may act, and its logs are redacted.
- **Language-server diagnostics** are shown in the result of an edit, so the agent sees the compiler's
  errors at once.
- A folder's own skills, hooks and extensions are now read from **`.agents/`** instead of pi's `.pi/`.

### A code index
- The agent gets `code_*` tools backed by a per-project index (tree-sitter, embedded in the binary,
  stored under `~/.mnemo`): definitions, callers and the impact of an edit for TypeScript, JavaScript,
  Python, Rust and Go. A call is tied to a definition only when the code says which one; the rest are
  counted, not guessed.
- It does not index a folder that is probably not one project, never reads what a read would be refused,
  and can be switched off per project or in `/settings`.

### Skills from marketplaces
- `mnemo skills` adds a marketplace (`owner/repo`, an https git address or a folder) and installs a
  plugin's skills from it. Nothing runs on install, paths stay inside the marketplace, and a skill whose
  files changed after install does not load.

### Remote view
- **`/remote`** serves a read-only view of the session on this machine only (loopback, a token for each
  start). It is off until you allow it with the `remote` setting.

### Planning, limits and speed
- Plan mode now tells the model it is planning, and an **`ask_user`** tool lets it put a question to you.
- New settings for turn and sub-agent limits (`maxTurns`, `subMaxTurns`, `subSpend`) and for compaction
  (`autoCompact`, `compactReserve`, `compactKeep`).
- **`--model`** picks the model for a run; a misspelled key is named; Bedrock is no longer chosen from one
  AWS variable; a 401, 402 or 403 stops the run instead of being retried.
- Every command, even `--version`, started in about 400 ms because one bundle held everything; pi, Ink and
  the memory client now load only for a session.

### Security
- **Commands get an allowlisted environment**, and so do MCP stdio servers. MCP over HTTP stays off
  unless the server's entry says `"allowNetwork": true`.
- **Egress rules**: `net` rules test the host of a command, a Python cell (by the address actually
  connected) and an MCP HTTP server, and cloud metadata addresses are refused in any spelling unless a
  rule allows them.
- **A managed policy** an administrator writes, which user and project settings cannot widen: allowed
  models, tools, MCP servers and a mode ceiling. A broken file fails closed.
- Deny rules now hold inside the Python tool (an audit hook asks before a cell starts a process or
  removes, renames or opens a file). It is a filter, not a sandbox.
- Mnemo switches off pi's own network habits (downloading ripgrep and fd, its model catalog,
  attribution headers): the only calls left are to your model provider and to places you name.

### Known
- The gate filters; it is not a sandbox (`SECURITY.md`).
