## What's new

### Agents that work together
- **Sub-agent settings.** Settings choose the model sub-agents run on and their turns, budget, thinking and
  context. A parent may lower any of them for one task, never raise one past yours.
- **`mnemo agents`** lists every agent running on the machine, in every terminal and project, and tells,
  steers or stops one from anywhere. Plain local files: no socket, no server. It shows each sub-agent's own
  model and limits.
- **Sub-agents are saved with the conversation**: each transcript and a `state.json` listing every agent a
  session started, plus `SubagentStart` and `SubagentStop` hooks.
- **Runs and `@N`.** Talk to any agent by its number. One prompt of yours is a run, capped at 40 messages and
  $1.00 of woken turns, and stopped as one.
- **A shared plan and log.** Agents on one run share a `TASK.md` and a `LOG.md`, claim steps with
  `task_update`, and see what the others did at each turn.
- **Agent profiles.** A sub-agent you use often, saved as one Markdown file (model, tools, limits,
  instructions) and started by name within your sub-agent settings.
- **Background sub-agents.** `spawn_subagent` can return at once; the answer comes back as a message while the
  parent keeps working.
- **Opera.** `mnemo opera` is a conductor that hands work to threads, each in its own git worktree, across
  several repositories (`docs/OPERA.md`).
- **`mnemo evolve`.** Run records, replayable task cards, a lesson playbook and versions you can revert
  (`docs/EVOLVE.md`). Sub-agents reflect on a run and keep team lessons.
- **Saved conversations.** `mnemo agents saved` finds, and `resume` reopens, every conversation on the machine.

### Memory
- **Background memory work.** Ingest, tidy and curate run on a timer, and the agent is told to open
  conversations it has not read.
- **Memories pinned to definitions.** `memory_remember` can point at a function; the fact reads as stale once
  that function changes.
- **Codex and opencode sessions** are read by `mnemo memory ingest`, next to Claude Code's and Mnemo's own.
- **The agent uses its own tools unasked** and tidies memory by itself.

### Code
- **`grep` without ripgrep.** A trigram text index behind `grep` for when `rg` is not installed.
- **Call-graph ranking.** `code_search` orders results by how much of the project calls them (PageRank).

### Safety
- **Skills are scanned before they are trusted** (SkillSpector rules).
- **Each agent is told only what is true for it**: a prompt names only the tools that agent has.

### Fixed
- Flaky Windows and macOS tests, at their cause (no fixed sleeps; the first frame sets raw mode first).
- A merge dropped memory anchor imports and broke the type-check; both are restored.

### Known
- The gate filters; it is not a sandbox (`SECURITY.md`).
- `mnemo update` on Windows can fail in `install.ps1` (`Get-FileHash` missing). Reinstall with the one-liner.
