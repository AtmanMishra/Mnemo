## What's new

### Fixed
- **A blank screen on startup when the memory sidecar does not answer.** Each memory call waited out its
  own 15 s timeout in turn, so a `memsrv` that started but never replied left the screen empty for about a
  minute (seen on Windows). Startup now waits 5 s for its first reply, does not ask a timed-out sidecar again
  for 60 s, and caps the intro's memory numbers at 2 s. Memory never holds up the first frame.

### Notes
- v0.2.0 is published (its first build failed the Windows installer check and was rebuilt after the deep
  uninstall fix, which it includes). 0.2.1 is the first release with the startup fix.
- If memory still reports as unavailable after updating, run `mnemo doctor` and check whether your antivirus
  blocks `memsrv`.

### Known
- The gate filters; it is not a sandbox (`SECURITY.md`).
- `mnemo update` on Windows can fail in `install.ps1` (`Get-FileHash` missing). Reinstall with the one-liner.
