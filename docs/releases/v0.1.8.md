## What's new

### A VS Code extension, and `mnemo --rpc`
- **`mnemo --rpc`** runs Mnemo as JSON lines on standard input and output, for an editor or any
  other front end (`docs/RPC.md`). A tool call that would ask becomes a `dialog` event and runs
  only when the client answers; there is no option that answers for it, and a client that goes
  away leaves every question answered "no". This is why the extension cannot be older than 0.1.8.
- **The extension** (`vscode/`, packaged as a `.vsix`) is a panel with chat, approvals with diffs,
  agents, memory and every setting, in its own look with a theme picker. If Mnemo is missing or too
  old, it offers to download this release, checks it against `SHA256SUMS` and keeps it in its own
  storage.

### Connect MCP servers
- Servers from `~/.mnemo/agent/mcp.json` (and a trusted folder's `.pi/mcp.json`) load as tools. They
  are found with `tool_search`, so their schemas stay out of a small model's prompt, and every call goes
  through the permission gate, with an `always` grant per tool. `/mcp` answers in Mnemo's own dialogs.

### Rewind and cost
- **`/rewind`** now puts back what shell commands and Python cells changed (in a git repository), not
  only the agent's own edits.
- **A dollar budget for a prompt** stops the prompt that crosses it, sub-agents' calls counted. A `-p`
  run prints one line of calls, tokens and dollars on stderr.
- `AGENTS.md` and `CLAUDE.md` reach the model, and the tests now check it.

### Security
- A grant for `git --version` no longer saves the whole program and allows `git push`; a skill approval
  shows the description that is loaded into later prompts.
- A downloaded folder can no longer run a command through `core.fsmonitor`, a git hook or a program of
  its own name on Windows before it is trusted.
- Recalled memory reaches the model inside a boundary a fact cannot close, marked as data, and is
  scanned again on the way out.
- A project's `.env`, private keys and `.netrc` are refused by the read tools like Mnemo's own key
  files (`.env.example` and public keys stay readable; an allow rule still opens one).
- An approved write is refused if its path was swapped for a symlink while the question was open.

### Known
- The extension has been run against a real `mnemo --rpc` in a browser and typechecked, but its
  download and launch code has not yet been exercised inside a running VS Code.
