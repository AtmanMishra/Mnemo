## What's new

### Agents talk to each other on their own
- **A message wakes an idle agent.** When a sibling or a sub-agent writes to an agent
  that is not working, the agent reads it at once and can answer; the answer wakes
  the sender in turn. You no longer have to prompt an agent so it notices a message.
- **Ask and wait.** `message_agent` with `wait` keeps the question open for up to two
  minutes and returns the reply as its result, so an agent can ask a sibling something
  and use the answer in the same turn. It stops waiting if that agent closes, and a
  sub-agent asking its own parent (busy waiting for it) is told to put the question in
  its answer instead of stalling for two minutes.
- **You see who said what.** A message from another agent appears in the conversation
  marked ✉, with who sent it and "another agent, not you". The playground feed says
  when a message woke an agent, or was held for you.

### Bounded
- A chain of messages is limited: each message counts one more than the one that led to
  it, and after 12 in a row since you last prompted, messages wait for your next prompt.
  Two agents cannot keep each other busy, and spending, forever. The agents page shows
  `✉ 2 waiting for you` on an agent holding them.
- A woken agent's edits and commands still go through its gate and ask you, as before.
  In `yolo` mode a message can now start an agent working without you: see `SECURITY.md`.

### Talk to a sub-agent
- **Type to a running sub-agent.** In a split, `alt+,` and `alt+.` now move through
  every pane, sub-agents included. A focused sub-agent pane has a prompt: what you send
  reaches it after its current step, as your words. `esc` goes back to the agent.

### Links survive a restart
- Two projects you linked are linked again when both are open, in a later run too, and
  the agent tells you so. `u` in the hub unlinks, and that is remembered as well.

### A spending allowance for woken turns
- Turns that messages start (and the sub-agents they start) may spend $0.50 per agent
  until you next prompt it. The call that crosses it stops the turn, messages to it then
  wait for you, and the agents page shows `$ woken turns spent`. You can let an agent
  talk to its siblings while you are away without it running up a bill.

### The playground's conversation view
- `c` shows the selected agent's messages with one other agent as a thread, each with
  its time and whether it woke the receiver; `tab` goes to its next partner.

### Interface
- **Your messages stand out**: a raised band with an accent rule down its left.
- **Sub-agents join the split by themselves** when their agent is on screen, in a free
  pane or one whose sub-agent finished. `ctrl+s` fills spare panes with the active
  agent's sub-agents.

### Fixed
- A sub-agent whose model call failed finished "without an answer" and no reason. The
  tool now fails with the model's error (a rate limit, say), for you and its parent.
- The playground's selection jumped to another agent when one above it started or
  ended; it now stays on the agent you chose.
- `s` on the agent you are in did nothing in the hub; it now says that agent always
  stays in the split.
- An agent whose session failed to start stayed listed on the agents page.

### Known
- The allowance counts what your provider prices; a local model that reports no price
  is bounded only by the chain of 12 messages.
- Links come back when both projects are open; Mnemo does not open a linked project
  for you.
