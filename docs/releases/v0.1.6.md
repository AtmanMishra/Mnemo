## What's new

### Agents talk to each other on their own
- **A message wakes an idle agent.** When a sibling or a sub-agent writes to an agent
  that is not working, the agent reads it at once and can answer; the answer wakes
  the sender in turn. You no longer have to prompt an agent so it notices a message.
- **Ask and wait.** `message_agent` with `wait` keeps the question open for up to two
  minutes and returns the reply as its result, so an agent can ask a sibling something
  and use the answer in the same turn.
- **You see who said what.** A message from another agent appears in the conversation
  marked ✉, with who sent it and "another agent, not you". The playground feed says
  when a message woke an agent, or was held for you.

### Bounded
- A chain of messages is limited: each message counts one more than the one that led to
  it, and after 12 in a row since you last prompted, messages wait for your next prompt.
  Two agents cannot keep each other busy, and spending, forever. The agents page shows
  `✉ 2 waiting for you` on an agent holding them.
- A woken agent's edits and commands still go through its gate and ask you, as before.
  In `yolo` mode a message can now start an agent working without you: see `SECURITY.md`.

### Interface
- **Your messages stand out**: a raised band with an accent rule down its left.
- **Sub-agents join the split by themselves** when their agent is on screen, in a free
  pane or one whose sub-agent finished. `ctrl+s` fills spare panes with the active
  agent's sub-agents.

### Fixed
- A sub-agent whose model call failed finished "without an answer" and no reason. The
  tool now fails with the model's error (a rate limit, say), for you and its parent.

### Known
- You talk to top-level agents only; sub-agents are watched, not typed to.
- Links last for the session; they are not restored on restart.
