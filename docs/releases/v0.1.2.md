## What's new

### Install, update, uninstall
- **`mnemo update`** installs the latest release with the same checksum-checked
  installer as the one-liner (`--check` only says whether there is one; `/update`
  does it from inside Mnemo). `mnemo update --auto on` adds a daily check at launch
  that tells you and never installs on its own. **Off by default.**
- **`mnemo uninstall`** removes the program and keeps what it learned;
  **`--deep`** also deletes `~/.mnemo` (memory, sessions, credentials, skills,
  logs, settings) after you type `delete`. The install scripts do the same:
  `sh -s -- --uninstall` / `--deep`, or `MNEMO_UNINSTALL=1` / `deep` on Windows.
- **The installers draw themselves** on a terminal: the wordmark, a pulse per
  step with the download counting up, and Mne at the end. Plain lines when piped.

### Safety
- **Your model-provider API keys stay out of commands the agent runs** (bash, the
  Python kernel, best-of checks). `MNEMO_PASS_ENV=NAME` hands one back.
- **The Python kernel is bounded**: a timeout per call (up to 600 s), stopped by
  esc, and an 8 GB memory cap on Linux.
- **Rewind.** `esc esc` on an empty prompt (or `/rewind`) goes back to an earlier
  message: the conversation, the files the agent edited since, or both.

### Memory
- **`mnemo memory tidy`** finds duplicate facts and pitfalls, facts about files
  that are gone, and what you marked wrong; `--apply` retires them.
- **Recall weighs trust**: what helped ranks higher, what you marked wrong twice
  is no longer recalled. In the memory pane, `+` / `-` vote, `e` edits, `d`
  forgets, and *Recalled this session* lists what came back.
- **Your own embedder**: `MNEMO_EMBED_URL` + `MNEMO_EMBED_MODEL` point search at
  an Ollama (or any OpenAI-compatible) embedding server.

### The interface
- **`ctrl+k`** on an empty prompt: one list of commands, agents, sessions and files.
- **`ctrl+f`** finds in the conversation; **`ctrl+o`** now expands output that was
  already printed.
- **`/resume`** shows titles, cost and how each session ended, and searches
  everything said in them. **`/stats`**: this session, the week, and which tools failed.
- **Clickable links**: file paths in tool calls and links in answers (OSC 8).
- **A desktop notification** when a long turn ends or an approval waits while you
  are in another window.
- **Every screen fits the terminal**, at any size and across resizes; the mouse
  wheel scrolls the conversation.
- **Full-terminal animations**: the launch, the introduction and the goodbye
  screen fill the whole window; Engram, the dither field Mne settles out of,
  also appears in the welcome card and the empty transcript.
- **Eleven themes** (`/theme`): Mnemo Night, Dracula, Nord, Gruvbox, Tokyo Night,
  Catppuccin Mocha, Synthwave, Amber CRT, Game Boy, Paper, Solarized Light.

### Also
- **`mnemo doctor --fix`** tightens permissions on Mnemo's files, sets a broken
  settings file aside, and reinstalls a missing memory sidecar.

## Fixes

- A long answer streaming in quickly could crash the workspace ("Maximum update
  depth exceeded").
- On Windows the installer can replace a running `mnemo.exe`, so `mnemo update`
  works from inside Mnemo; the PowerShell installer forces TLS 1.2 and no longer
  crawls behind PowerShell's progress bar.
- A fresh install made `~/.mnemo` readable by other users; it is now private.

Install or upgrade: `curl -fsSL https://mnemo.atmanmishra.dev/install.sh | sh`
(Windows: `irm https://mnemo.atmanmishra.dev/install.ps1 | iex`), or `mnemo update`
from now on.
