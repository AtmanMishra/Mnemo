## What's new

- **Updates.** `mnemo update` installs the latest release with the same
  checksum-checked installer as the one-liner (`--check` only says whether there
  is one); `/update` does it from inside Mnemo. `mnemo update --auto on` adds a
  daily check at launch that tells you about a new version and never installs on
  its own. It is **off by default**: until you turn it on, Mnemo contacts nothing
  but your model provider. Homebrew and Scoop installs are pointed to
  `brew upgrade` / `scoop update`.
- **The mouse wheel scrolls the conversation** in the full-screen workspace (and
  an open preview). Hold Shift (Option in some terminals) to select text, or
  `/mouse` / `MNEMO_MOUSE=0` to give the mouse back to your terminal.
- **Engram in the terminal.** The launch sequence writes Mne and the wordmark in
  out of a drifting field of dither glyphs; the welcome card and the empty
  transcript have their own variations of the same piece.
- **Thinking looks like thinking**: an ordered-dither field while the model
  thinks, a writing pulse while the answer streams, and a live pulse on busy
  agents in the hub.

## Fixes

- A long answer streaming in quickly could crash the workspace ("Maximum update
  depth exceeded"). Layout is now measured at most once a frame.
- On Windows the installer can replace a running `mnemo.exe` / `memsrv.exe`
  (it moves the running copy aside), so `mnemo update` works from inside a
  running Mnemo.

Install or upgrade: `curl -fsSL https://mnemo.atmanmishra.dev/install.sh | sh`
(Windows: `irm https://mnemo.atmanmishra.dev/install.ps1 | iex`), or `mnemo update`
from 0.1.2 on.
